from orders

Edge Functions

Server-side logic, deployed next to your users.

Write TypeScript, deploy with a single command, and it runs on Deno at the edge — close to wherever the request came from. Reach for it when a policy alone isn't enough: webhooks, third-party calls, scheduled jobs.

functions/send-receipt/index.ts deployed 
import { createClient } from "@supabase/supabase-js"

Deno.serve(async (req) => {
  const { order_id } = await req.json()
  const db = createClient(URL, KEY)

  const { data } = await db
    .from("orders")
    .select("*, customers(email)")
    .eq("id", order_id)
    .single()

  return new Response("sent")
})

Realtime

Listen to your database, live.

Subscribe to inserts, updates and deletes as they happen in Postgres, broadcast messages between clients, or track who's present in a room — all over the same connection, no separate pub/sub service to run.

  • Postgres change data capture, filtered per client
  • Presence and cursor state for multiplayer UI
