Full-stack cloud

One platform, four ways to run a model.

Serverless when you want an endpoint in a minute. Dedicated when you need the whole GPU. Fine-tuning when the base model isn’t quite yours yet.

Serverless inference

Call 200+ open models — Llama, Qwen, DeepSeek, FLUX — through one API. Pay per token, no cold starts, no capacity to plan for.

  • Sub-100ms time-to-first-token on Turbo endpoints
  • Chat, vision, image, audio and code models
  • Drop-in OpenAI-compatible SDK

inference.py

# chat completion against an open model
from together import Together

client = Together()
response = client.chat.completions.create(
    model="meta-llama/Llama-3.3-70B",
    messages=[{"role": "user", "content": "explain LoRA"}],
    stream=True,
)

Fine-tuning

Bring your dataset, pick a base model, and get back weights you own — full fine-tunes or LoRA adapters, no infrastructure to babysit.

  • LoRA and full parameter fine-tuning
  • Export weights any time, no lock-in
  • Serve the result serverless the moment it’s done

finetune.py

# launch a LoRA fine-tune job
client.fine_tuning.create(
    training_file="file-b8c19...",
    model="meta-llama/Llama-3.3-70B",
    lora=True,
    n_epochs=3,
)

GPU clusters

Reserved H100 and H200 clusters with InfiniBand networking, for teams training their own models instead of adapting someone else’s.

  • H100 / H200 with InfiniBand at cluster scale
  • Slurm or Kubernetes, your choice
  • Monthly or reserved-term pricing

cluster.yaml

# reserve a training cluster
cluster:
  gpu: h200
  nodes: 32
  interconnect: infiniband
  scheduler: slurm

Dedicated endpoints

A model pinned to hardware only you use — fixed latency, private weights, autoscale rules you set instead of a shared queue.

  • Single-tenant GPU, no noisy neighbors
  • Autoscale floor and ceiling you define
  • Your fine-tuned weights, private by default

deploy.py

# stand up a dedicated endpoint
client.endpoints.create(
    model="org/custom-70b-lora",
    hardware="1x_h100",
    autoscale={"min": 1, "max": 4},
)
