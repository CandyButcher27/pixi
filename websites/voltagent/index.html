Agents are code, not a black box.

tools

Give agents real capabilities: call a function, hit an API, or connect any MCP server without writing glue code.

memory

Conversation history and long-term recall out of the box, backed by SQLite, LibSQL, or Postgres.

subAgents

Compose a supervisor agent that delegates to specialists and coordinates multi-step work across a team.

voice

Real-time speech in and out, so an agent can run a phone call as naturally as a chat thread.

workflow

Chain deterministic steps with agent reasoning for when a plain function isn't enough and a loose agent is too much.

llm

Swap OpenAI, Anthropic, Google, or Groq with one config key — any Vercel AI SDK provider, no rewrites.

Watch every step, in production.

VoltOps is a visual console for the agents you already built: live traces, replay any run, and a graph of who called what, in what order, with which model. No SDK lock-in — instrument what you have.

npm create voltagent-app@latest

One command scaffolds an agent, wires a model provider, and starts the VoltOps dev server.

agent.ts 
import { Agent, VoltAgent } from "@voltagent/core";
import { openai } from "@ai-sdk/openai";

const supportAgent = new Agent({
  name: "support-agent",
  instructions: "Triage incoming tickets and draft a reply.",
  llm: openai("gpt-4o-mini"),
  tools: [lookupOrder, refundOrder],
});

new VoltAgent({ agents: { supportAgent } });
