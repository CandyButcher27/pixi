One SDK

Six lines to know everything

Drop the snippet in once. Pageviews, clicks and custom events start flowing in immediately — the same SDK carries feature flags, replay and surveys, so there's nothing extra to install later.

JavaScript Python Node React Native iOS Android Go Ruby PHP 
import posthog from 'posthog-js'

posthog.init('phc_your_project_key', {
  api_host: 'https://us.i.posthog.com',
})

// that's it — capture a custom event whenever you need one
posthog.capture('cta_clicked', { plan: 'free' })

Roll out gradually, watch the metric move

Check a flag anywhere the SDK is loaded. The client evaluates it locally after the first fetch, so gating a feature never adds a network round trip on the critical path.

if (posthog.isFeatureEnabled('new-onboarding')) {
  renderNewOnboarding()
} else {
  renderDefault()
}
💡Tip — start a rollout at 1%, watch conversion and error rate for a day, then ramp to 10%, 50%, 100%.
✅Success — once a flag is fully rolled out, delete it. A codebase full of 100%-on flags is just dead code with a UI.
