How it works

  1. 01

    Pick a model

    Choose from thousands of open-source models covering image, video, audio and language — each one packaged and versioned.

  2. 02

    Call the API

    Send input in Python, Node.js, cURL or plain HTTP. No containers to build, no GPUs to provision.

  3. 03

    Get your output

    Replicate schedules the run on a cloud GPU and streams the result back — you only pay for the seconds you use.

import replicate

output = replicate.run(
    "meta/llama-3-70b-instruct",
    input={"prompt": "Explain diffusion models simply"}
)

print(output)
import Replicate from "replicate";

const replicate = new Replicate();

const output = await replicate.run(
  "meta/llama-3-70b-instruct",
  { input: { prompt: "Explain diffusion models simply" } }
);

console.log(output);

  -H "Authorization: Bearer $REPLICATE_API_TOKEN" \
