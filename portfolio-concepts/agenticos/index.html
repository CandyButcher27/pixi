AgenticOS is a monorepo of independent tools — a model router, a design-generation pipeline, a retrieval curriculum, a security layer — built to be used alone or wired together.

see the modules
// architecture

Every module speaks through one router.

Token-router sits in the middle: a caller sends a prompt, it picks the best available free or cheap model from a hand-verified catalog, and returns the response. Everything else in the monorepo calls through it instead of hard-coding a provider.

// modules

Independent by design, composable by router.

Most of this is early-stage. Nothing here pretends to be finished — the status line under each card is honest about where it stands.

01 / router

Token-router

Picks the best available free or cheap model from a hand-curated, key-verified catalog — Groq, OpenRouter, Gemini, Ollama Cloud — via litellm. Exposed as a FastAPI endpoint and an MCP tool.

active
02 / design

Frontend

A design-reference catalogue and generation pipeline — ~75 static site homages indexed by screenshot + VLM metadata, retrieved semantically to compose new pages. Driven entirely through the router.

active
03 / retrieval

RagForge

A twelve-level adaptive-retrieval curriculum — from naive chunking up through query rewriting, reranking, and agentic RAG. Planning-only for now; the PRD is written.

planning
04 / security

CyberSecrity

Reserved for defensive tooling pulled out of the cybersec inspirations — fraud/mule detection, convergence-based alerting, the patterns proven in MulePredator.

placeholder
05 / ingest

Scraper

Data acquisition layer feeding the rest of the system — not yet built, reserved so retrieval and detection modules have a real source instead of static fixtures.

placeholder
06 / reference

inspirations/

Studied, not shipped — hackathon token-routing entries, cybersecurity repos, and trading systems pulled in for pattern research, kept out of the core codebase's own logic.

reference

Nothing here is a framework you adopt whole. Each module works alone — the router is what lets them work together.
