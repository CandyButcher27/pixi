How attribution works

Read the query, not the dashboard.

  1. Instrument once, at the driver

    The agent wraps your database driver, HTTP client and queue consumer. Every span carries the normalized statement and its bind shape, never the bound values.

  2. Group by fingerprint, not by URL

    Two routes that run the same unindexed join are one problem. Spanwise collapses them so a fix shows up once, with its total cost across services.

  3. Rank by time lost

    Calls multiplied by excess latency over the route's own baseline. A rare 9-second report job ranks below a 40 ms query that runs two million times a day.

  4. Explain against the deploy

    Each regression links to the commit range, the plan change Postgres reported, and the rows-examined ratio before and after.
