Rows and columns, one engine.

Basalt is a Postgres-compatible database that writes transactions to a row store and answers analytics from a columnar copy of the same data — kept consistent by the same WAL. No pipeline, no second system, no sync job to babysit.

How it works

Ask once.

  1. Write to rows
  2. WAL folds to columns
  3. Planner picks per scan
  4. One snapshot

One query, both engines.

psqlbasalt@prod-eu-1snapshot 0x7f3a…c2
basalt=> EXPLAIN ANALYZE
SELECT c.region, date_trunc('week', o.created_at) AS wk,
       sum(o.total) AS revenue, count(*) AS orders
FROM   orders o JOIN customers c USING (customer_id)
WHERE  o.created_at > now() - interval '90 days'
GROUP BY 1, 2;  -- 1.2B rows, still OLTP-hot
HashAggregate  (rows=1196)  212 ms
  -> ColumnScan on orders  segments=418/3120 pruned  164 ms
  -> RowIndexScan on customers_pkey  (rows=48 211)  9 ms
Snapshot: lsn 9F/3A11C2D8 · freshness lag 31 ms

Writes land in the row store and the WAL, exactly like Postgres. A background applier folds committed pages into compressed column segments within ~40 ms. The planner then picks per scan — point reads hit rows, aggregates hit columns — and both paths read the same snapshot, so results never disagree.

Internals

Nothing hidden.

Every layer is in the repo, documented in /design, and replaceable by an extension.

Row store
Heap pages with MVCC tuples and B-tree, GIN and BRIN indexes. Byte-compatible with Postgres 16 on-disk format, so pg_upgrade works in both directions.
src/heap
Column store
Immutable 1M-row segments, zstd + dictionary encoding, min/max zone maps for pruning. Rebuilt incrementally from the WAL by the applier.
src/colseg
Planner
Postgres cost model plus a scan-choice pass. Override per query with SET basalt.scan = 'column' when you know better.
src/plan
Replication
Raft over the WAL stream. Followers serve consistent reads with AS OF SYSTEM TIME; failover in under 4 seconds.
src/raft
Extensions
Runs pgvector, PostGIS, pg_cron and pg_stat_statements unmodified. 212 extensions pass the compat suite.
compat/ext
