CREATE TABLE features

One engine. Rows when you write, columns when you ask.

01

Serializable by default

MVCC with strict serializable isolation. No anomaly tables to memorise, no surprise write skew.

ACID
02

Adaptive storage

Hot rows live in a B-tree; cold partitions compact into compressed columnar segments automatically.

HTAP
03

Postgres wire protocol

Point psql, your ORM, or any driver you already use. Most apps migrate by changing a connection string.

COMPAT
04

Raft replication

Add a node, Quarry rebalances. Lose a zone, it keeps serving. Consensus is built in, not bolted on.

HA
05

Vectors and JSON, natively

Index embeddings and documents next to relational data. One query planner, one transaction.

-- one transaction, three shapes of data
BEGIN;
INSERT INTO orders (id, customer, meta)
  VALUES (gen_id(), 4821, '{"channel":"web"}');

SELECT sku, sum(qty)
  FROM line_items
 WHERE placed_at > now() - '30 days'
 GROUP BY sku;            -- columnar scan

SELECT id FROM products
 ORDER BY embedding <-> $1
 LIMIT 10;                -- vector index
COMMIT;
