    How it works

    From deploy to the guilty line in one query.

    1. Wrap the app, not every function.

      The agent hooks your framework's router and database driver. Each request becomes a span tree with handler, SQL, cache and outbound HTTP calls already attached. No decorators, no manual spans.

    2. Group by what you actually change.

      Latency and cost roll up by route, by query fingerprint and by git SHA. Ask p99 by route where sha = HEAD and see which endpoint your last deploy made slower.

    3. Follow it to the source line.

      Every regression links to the file and line that issued the slow query, with the before and after query plans side by side. Paste the link into the PR.

    4. Set budgets, get paged less.

      Give each route a latency and cost budget. Quarry alerts on the budget breach, not on CPU, so the page you get at 3am already names the handler.
